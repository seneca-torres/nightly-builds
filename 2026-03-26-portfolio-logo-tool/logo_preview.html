How to Use This Tool

  3. Preview on site - Click "Preview on Portfolio" to see how the logo looks on the actual VT Sports Solutions website.
  4. Apply to portfolio - Once you've selected a logo, click "Apply to Portfolio" to copy it to the portfolio images directory.
  5. Test locally - After applying, open ~/clawd/portfolio/index.html in your browser to see the new logo in context.

Note: This tool doesn't modify the actual portfolio HTML/CSS, only copies logo files. You may need to update CSS classes or image references in the portfolio code.
