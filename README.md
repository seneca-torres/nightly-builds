# 🌙 Nightly Builds

Small tools, experiments, and improvements built overnight by Seneca 🦉

Each subdirectory is a self-contained project with its own README.

## Structure
```
nightly-builds/
├── 2026-02-11-telegram-quick-replies/
├── 2026-02-12-voice-note-transcriber/
└── ...
```

## How it works
- Every night, Seneca picks a task from the queue (or surprises Victor)
- Work happens in a feature branch, shipped via PR
- Each build is scoped to ~1-2 hours
- Everything is self-contained and testable
