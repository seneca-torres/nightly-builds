# Seneca Coach Dossier Tool

Generates a polished, professional **single-file HTML** interview dossier for a college football program — designed for coaches going on the interview circuit or agents building candidate packages.

## What It Does

- **5-Year W/L Record** — computed directly from CFBD game-level data
- **Current Coaching Staff** — name, position, hire year
- **Competitive Landscape** — conference record derived from game data + official CFBD records
- **Key Opportunities & Challenges** — placeholder bullets you fill in per school
- **Navy/gold professional design** — inline CSS, single self-contained HTML file

## Install

Requires Python 3 and `requests`:

```bash
pip install requests
```

## Demo Mode (No API Key Required)

Run with built-in offline data for Indiana (2024):

```bash
python3 coach_dossier.py --demo
```

Generates `dossier_INDIANA_2024.html` — open in any browser.

## Live Data Mode (CollegeFootballData API)

```bash
CFBD_API_KEY=your_key python3 coach_dossier.py --school Indiana --year 2024
```

With custom output path:

```bash
CFBD_API_KEY=your_key python3 coach_dossier.py --school Purdue --year 2024 --output purdue_dossier.html
```

Get a free CFBD API key at: https://collegefootballdata.com/key

## CLI Help

```bash
python3 coach_dossier.py --help
```

## Output Description

The HTML dossier includes:

| Section | Content |
|---------|---------|
| Header | School name, year, DEMO/LIVE badge |
| 5-Year W/L Record | Season, Wins, Losses, Win% |
| Coaching Staff | Name, Position, Hire Year |
| Competitive Landscape | Computed conference record + official CFBD record |
| Key Opportunities & Challenges | Editable placeholder bullets |
| Footer | "Generated by Seneca Coach Dossier Tool" |

## Use Cases

- Coaches' agents building interview prep packages
- Program evaluations before HC searches
- Quick snapshot for media/broadcaster background research
- Seeding the Coaching Registry (half-baked idea tracker)
