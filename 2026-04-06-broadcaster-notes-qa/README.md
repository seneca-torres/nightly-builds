# Broadcaster Notes Q&A System 🎤

A natural language question-answering system for broadcaster notes that allows querying converted markdown files with questions like:
- "every coach I've talked to who went from SEC to Big Ten"
- "show me all notes about Michigan coaches from 2025"
- "which coaches moved from Alabama to other schools in 2024?"

This tool implements semantic search over markdown notes with YAML frontmatter, extracting entities (coaches, schools, conferences, dates) and providing context-aware answers.

## Features

- **Natural language queries** - Ask questions in plain English
- **Semantic search** - Uses sentence-transformers embeddings for accurate results
- **Entity recognition** - Automatically extracts coaches, schools, conferences, dates
- **Filtering** - Filter by date range, school, conference, or coach
- **Multiple outputs** - Text, markdown, and JSON formats
- **Web interface** - Optional Flask-based web UI for easy querying
- **Demo mode** - Includes sample broadcaster notes for testing

## Installation

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# For sentence-transformers (optional, needed for semantic search)
pip install sentence-transformers
```

## Quick Start

```bash
# Build index from sample data
python main.py build-index --notes-dir sample_data

# Ask a question
python main.py ask "Which coaches moved from SEC to Big Ten?"

# Use demo mode
python main.py demo "Show me Michigan coaches from 2025"

# Start web interface
python main.py serve
```

## CLI Usage

```bash
# Build index from markdown notes
python main.py build-index --notes-dir ./notes --index-dir ./index

# Ask questions
python main.py ask "query" [--format text|markdown|json] [--limit 5]

# Filter results
python main.py ask "coaches" --from-date 2024-01-01 --to-date 2024-12-31
python main.py ask "coaches" --school "Michigan" --conference "Big Ten"

# Run demo with sample data
python main.py demo "query"

# Start web server (port 8080)
python main.py serve
```

## Sample Data Format

Broadcaster notes should be markdown files with YAML frontmatter:

```yaml
---
date: 2025-03-15
school: Michigan
conference: Big Ten
coach: Sherrone Moore
coaches: [Sherrone Moore, Jesse Minter]
schools: [Michigan, Alabama]
conferences: [Big Ten, SEC]
movement_history: |
  Sherrone Moore promoted to head coach after Jim Harbaugh left for NFL
  Jesse Minter followed Jim Harbaugh to Chargers
tags: [head-coach, promotion, 2025]
---

# Notes from Michigan spring practice

Spoke with Sherrone Moore about the QB competition...
```

## Advanced Usage

### Custom Entity Lists
You can extend the entity recognition by adding to the lists in `qa_engine.py`:
- `COACHES_LIST`
- `SCHOOLS_LIST` 
- `CONFERENCES_LIST`

### Performance Tuning
- Adjust `chunk_size` in `vector_store.py` for different note lengths
- Modify `similarity_threshold` for result filtering
- Use different embedding models (change `model_name` in `vector_store.py`)

### Index Management
- Rebuild index when notes change: `python main.py build-index`
- Index files are stored in `./index/` by default
- Old indexes are automatically backed up

## Troubleshooting

**"No module named 'sentence_transformers'"**
- Install with: `pip install sentence-transformers`
- Or use the fallback keyword search mode

**"No notes found"**
- Check that notes have proper YAML frontmatter
- Verify the `--notes-dir` path is correct

**"Query returns unrelated results"**
- Try rebuilding the index
- Adjust the `--limit` parameter
- Check that notes contain relevant entities
